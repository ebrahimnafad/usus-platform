# 03: JoinParts, Number Bonds, and MATCHING (Lessons K-27 to K-31)

**What to build:** The Number Bond and Equation Strip Visual Models, the `JoinParts` (اجمع الجزأين) archetype, seed-chosen addition facts, the `ConnectMatch` extensions for the MATCHING Brain Builders, and complete localized blueprints, Answer Keys, and Teacher Notes for K-27 to K-31.

**Blocked by:** 02: Bring K-1 to K-26 into compliance with the layout guard

**Status:** ready-for-agent

- [ ] **Number Bond** Visual Model: Total circle on top, two Part circles below, first Part on the right; 56 px circles in a 212 × 160 px box; any circle can hold a digit, an `unknown` Answer Slot, or a solved digit, so Unit 4 can reuse it
- [ ] **Equation Strip** Visual Model: 48 px tall, right-to-left (`٣ + ٢ = ٥`), any term can be an Answer Slot; supports the total-first form for later tickets
- [ ] Five frames show two Parts with two-tone counters and dashed outlines around each Part
- [ ] `JoinParts` supports representations (five frame, snap cubes, tally marks, dice/domino, pictures), response forms (parts-and-total table, Number Bond, Equation), and actions (trace, write, draw counters into an empty five frame)
- [ ] The Total is the unknown, except that a Part may be unknown in Challenge & Assessment or at Advanced
- [ ] Blueprints declare limits and the Seed picks facts: no fact repeats within an exercise; across the sheet unused facts come first; `٣ + ٢` and `٢ + ٣` are different facts
- [ ] Difficulty follows the spec: Easy (Total ≤ 4, model shown, trace), Intermediate (Total ≤ 5, model shown, write), Advanced (model partly withdrawn, 0 allowed as a Part)
- [ ] `ConnectMatch` gains Number Bond, Equation, parts-table, and tally-expression endpoints and an optional "write the missing Total" slot per row, covering MATCHING A–D
- [ ] Practice uses each lesson's Workbook question types; Challenge & Assessment uses one Brain Builder and one Problem of the Day question
- [ ] Arabic titles, Teacher Notes, classroom activities, misconceptions, prompts, and Strategy Hints for K-27 to K-31 are drafted and reviewed by the user
- [ ] Answer Keys show filled Number Bonds, drawn counters, solved tables, and a Strategy Hint on every exercise
- [ ] Domain tests: across many seeds every Number Bond satisfies Part + Part = Total and every fact respects its limits
- [ ] Constitution §12 holds for K-27 to K-31 (guard green for K-1 to K-31)
